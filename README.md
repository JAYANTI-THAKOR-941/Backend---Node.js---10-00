# Node.js Backend Classroom Examples

A collection of independent Node.js backend exercises covering HTTP servers, Express, EJS, static assets and CRUD projects.

## Project structure

`custom-http-server/`, `express-server/`, `express-static/`, `ejs-server/`, `curd-operation-array/`, `NextGenStore/`, `bookStore/`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/Backend---Node.js---10-00.git
cd Backend---Node.js---10-00
```

Enter the individual exercise directory and run `npm ci` where a lockfile exists (otherwise `npm install`). Review its package scripts or server entry point. Database-backed exercises require local database configuration.
